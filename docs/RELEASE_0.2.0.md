# v0.2.0 — ChatGPT 통합 앱 호환 업데이트

## 핵심 변경

- `ChatGPT.exe` 호스트와 기존 `Codex.exe`를 함께 감지하고 종료합니다.
- 강제 종료 전에 `CloseMainWindow()`로 정상 종료를 요청합니다.
- 계정을 떠나기 직전에 현재 `auth.json`을 해당 계정 번들에 체크포인트합니다.
- 모든 중요한 JSON과 인증 파일을 원자적으로 기록합니다.
- 손상 JSON을 백업에서 자동 복구하고 암호화 번들에서 계정 카탈로그를 재구성합니다.
- 중복 계정 저장을 최신 인증 갱신 동작으로 변경했습니다.
- 전환 후 설치된 Windows ChatGPT/Codex 앱을 자동 재실행합니다.
- 깨져 있던 한국어 UI와 사용자 문서를 복원했습니다.

## 보존 범위

계정 전환은 공용 Codex 홈의 `auth.json`만 변경합니다. 채팅, 프로젝트, 설정, 플러그인, 스킬, 메모리 및 SQLite 상태 파일은 변경하지 않습니다.

## 마이그레이션

v0.1.x의 `%USERPROFILE%\.oauth-account-switcher` 폴더를 그대로 사용합니다. 첫 실행 시 `.bak`과 기존 암호화 번들을 이용해 가능한 범위에서 자동 복구합니다.

v0.1.x가 저장한 refresh token이 이미 교체된 계정은 공식 로그인을 한 번 수행하고 **현재 계정 저장 또는 갱신**으로 다시 저장해야 할 수 있습니다. 이후 전환부터는 최신 회전 토큰이 자동 체크포인트됩니다.
