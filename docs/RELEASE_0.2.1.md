# v0.2.1 — 종료 버튼 및 자동 재시작 설정

## 핵심 변경

- 상단 종료 버튼을 빨간색 **ChatGPT/Codex 종료** 버튼으로 바꿔 즉시 찾을 수 있게 했습니다.
- **전환 시 자동 종료·재시작** 토글을 추가했습니다.
- 토글은 기본적으로 켜져 있으며 선택값을 `app-state.json`에 원자적으로 저장합니다.
- 자동 모드에서는 계정 전환 전에 ChatGPT/Codex를 안전하게 종료하고 전환 후 다시 실행합니다.
- 수동 모드에서는 앱이 완전히 종료된 경우에만 인증을 전환하고 자동 재실행하지 않습니다.
- 수동 모드에서 앱이 열려 있으면 인증 파일을 변경하지 않고 빨간 종료 버튼을 누르도록 안내합니다.
- 인증 교체 직전 프로세스 상태를 다시 검사해 종료 직후 앱이 다시 열린 경우도 차단하거나 재종료합니다.

## 보존 범위

v0.2.0과 동일하게 공용 `%USERPROFILE%\.codex` 홈을 유지하며 `auth.json` 외의 채팅, 프로젝트, 설정, 플러그인, 스킬, 메모리 및 SQLite 상태 파일은 변경하지 않습니다.

## 업그레이드

v0.2.0 위에 그대로 설치할 수 있습니다. 기존 `app-state.json`에 새 설정이 없으면 자동 종료·재시작이 켜진 상태로 시작하므로 기존 전환 동작이 유지됩니다.
