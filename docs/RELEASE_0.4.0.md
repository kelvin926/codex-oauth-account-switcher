# v0.4.0

계정 전환에 사용량 분석과 관리 기능을 추가했습니다.

- 사용량 분석: 시간별, 날짜별, 주별, 월별 및 사용자 지정 기간. 계정, 모델, 리즈닝 옵션 필터와 CSV 내보내기.
- 토큰 상세: 입력, 캐시 입력, 캐시 쓰기, 출력, 추론, 총토큰과 개별 기록. 입력에는 캐시 입력이, 출력에는 추론 토큰이 포함됩니다.
- 주간 한도와 크레딧의 서버 관측 이력. 모델별 주간 한도 소모는 제한된 관측 구간의 토큰 비율로 배분한 추정값입니다.
- 트레이에서 현재 계정과 잔여량 확인, 빠른 전환. 창을 닫으면 기본적으로 트레이에 유지하며 메뉴에서 종료할 수 있습니다.
- 1~15분 주기의 사용량 자동 갱신, 잔여량 부족과 한도 복구 알림. 기본 5분, 알림 기준 잔여 20%.
- 초기화권 만료일 등 상세 조회와 1개 수동 사용. 소모 전 계정을 확인하며, 결과가 불명확한 요청은 자동 재전송하지 않습니다.
- 추천 방식 선택: 잔여 용량, 초기화 임박, 지정 계정 우선. 계정별 우선순위와 추천 제외.
- 공식 Codex CLI를 통한 계정 추가와 재로그인. 별도 로그인 폴더를 사용하고 재로그인 시 대상 계정을 검증합니다.
- 전환 단계 표시, 설치와 인증 진단, 최근 작업 기록, 마지막 전환 직전 인증으로 복구.

## 사용량 분석을 읽는 방법

설치 후 `사용량 분석`의 `기록 가져오기`로 로컬 Codex 기록을 읽습니다. 많은 기록은 여러 수집 주기에 나누어 처리합니다. 앱이 열려 있는 동안 30초마다 새 기록을 가져옵니다.

- 분석 원본은 `CODEX_HOME` 또는 `%USERPROFILE%\.codex`의 `sessions`와 `archived_sessions` JSONL입니다. 다른 PC, 클라우드 및 이 PC에 저장되지 않은 작업은 포함하지 않습니다.
- 과거 로그의 계정 생성 정보는 실제 과금 계정으로 취급하지 않습니다. 설치 전 로그와 확인 불가능한 기록은 `계정 미확인`으로 남습니다.
- 계정 귀속은 전환기가 실행 중 관측한 현재 로그인 구간에 기반한 추정입니다. 같은 로그인 관측이 90초 이내로 이어져야 하며, 앱 재시작과 계정 전환은 구간을 끊습니다. 프록시 사용은 정확한 계정 귀속을 보장하지 않습니다.
- 모델과 리즈닝은 해당 로컬 로그에 기록된 설정입니다. 서버의 실제 추론 강도나 요금표를 의미하지 않습니다.
- 주간 소모 추정은 같은 초기화 주기의 15분 이내 서버 관측 사이에서 증가한 사용률을, 해당 계정으로 추정된 로컬 총토큰 비율로 배분합니다. 전체 구간이 연속 로그인 관측으로 덮인 경우만 계산합니다. 특정 계정 선택 시 표시됩니다.
- 다른 기기 사용, 서버 반영 지연, 정수 반올림 때문에 모델별 실제 한도 소모와 다를 수 있습니다. 토큰별 고정 소모율이나 청구 금액으로 해석하면 안 됩니다. 관측되지 않은 구간은 0으로 채우지 않습니다.
- 여러 초기화 주기를 포함하면 주간 소모 추정 합계가 100%p를 넘을 수 있습니다. 달력상 주별 집계와 계정 한도의 초기화 주기는 별개입니다.
- 복사된 세션의 이벤트는 중복 제거하고, 상속된 fork 기록과 감소한 누적값은 새 사용량으로 합산하지 않습니다. 누락된 누적 토큰을 특정 모델에 임의 배정하지 않습니다.
- 저장 상한은 최근 토큰 이벤트 25만 개, 서버 한도 관측 10만 개이며 초과하면 안내를 표시합니다. 조회 시간은 PC의 시간대입니다.
- 통계 저장소에는 대화 내용, 도구 결과 및 인증 토큰을 기록하지 않습니다. 원본 대화 파일은 변경하지 않습니다.

## 인증과 초기화권

브라우저 로그인에는 설치된 Codex 앱 또는 CLI의 `codex.exe`가 필요합니다. `설정과 진단`에서 설치 상태를 확인할 수 있습니다. 기기 코드 로그인을 사용하며 새 계정의 인증은 먼저 별도 폴더에 저장합니다. 현재 사용 중인 계정에 다시 로그인한 경우, 앱 내 확인 후 Codex를 종료하고 새 인증을 적용합니다.

초기화권 사용 요청은 전송 전 기록하고 서버의 `redeem_request_id`를 사용합니다. 응답 유실이나 알 수 없는 결과에서는 추가 소모를 차단합니다. 정상 사용 후 잔여량 조회만 실패했다면 사용 버튼을 다시 누르지 말고 갱신하세요.

## 검증 범위와 출처

파서, 증분 수집, 계정 귀속, 초기화 경계, 필터 계산, 초기화권 소모 실패 및 로그인 취소 경합을 fixture와 mock으로 검증했습니다. Windows CI는 테스트와 설치 패키지 빌드, 실제 EXE의 계정 화면과 분석 화면 표시를 검사합니다. 실제 사용자 계정 로그인이나 초기화권 소모는 배포 과정에서 실행하지 않습니다.

- [OpenAI Codex protocol](https://github.com/openai/codex/blob/main/codex-rs/protocol/src/protocol.rs)
- [OpenAI Codex reset-credit client](https://github.com/openai/codex/blob/main/codex-rs/backend-client/src/client/rate_limit_resets.rs)
- [OpenAI Codex App Server](https://learn.chatgpt.com/docs/app-server)
- [OpenCodex account controls](https://github.com/lidge-jun/opencodex/blob/main/structure/codex-account-controls.md)

OpenCodex는 기능 설계 참고용으로 사용했으며 구현 코드를 복사하지 않았습니다.
