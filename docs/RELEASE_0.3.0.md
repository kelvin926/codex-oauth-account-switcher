# v0.3.0

## 수정 내용

- 계정 전환 후 `explorer.exe`와 `shell:AppsFolder`를 호출하던 코드를 제거했습니다. Windows 앱 활성화 API로 실행해 불필요한 문서 폴더 열림과 탐색기 경유 실행을 방지합니다.
- 패키지에 실행 항목이 여러 개 있을 때 잘못된 앱 ID를 만들던 처리를 수정했습니다. 하나로 식별되지 않으면 직접 실행 안내를 표시합니다.
- Pro의 주간 한도만 반환되는 응답을 지원합니다. 한도의 유무와 기간은 서버 응답을 따르며, 없는 5시간 한도를 0%로 만들지 않습니다. 주간 한도가 첫 번째 슬롯에 오는 경우도 지원합니다.
- 초기화 시각이 없을 때 현재 시각을 만들어 표시하던 오류를 수정했습니다.
- 한도에 도달했거나 사용량 확인에 실패한 계정을 자동 추천하지 않습니다. 예전 프로모션 10배 및 근거 없는 조직 계정 100배 가중치를 제거했습니다. 추천 점수는 실제 메시지 수가 아닌 비교용 추정 점수입니다.
- 활성 계정의 사용량 갱신은 최신 `auth.json` 토큰을 사용하고 저장 번들을 갱신합니다. 워크스페이스 ID도 요청에 포함합니다.
- 사용량 요청에 15초, PowerShell 작업에 20~30초 제한 시간을 적용했습니다. 백그라운드 PowerShell 창을 숨겼습니다.
- 연속 클릭과 중복 실행으로 전환이 여러 번 예약되거나 인증 파일이 충돌하는 문제를 방지했습니다.
- 유휴 상태의 주기적 PowerShell 실행과 불필요한 JSON 저장을 제거하고, 상태 조회 요청이 쌓이지 않도록 했습니다.
- 공식 로그아웃으로 `auth.json`이 없어도 저장된 계정으로 전환할 수 있습니다. 실패 시 원래의 로그아웃 상태로 복원합니다.
- 최종 앱 종료 후 최신 토큰을 저장하고, 대상 번들의 계정 ID를 검증합니다.
- 계정 저장 실패 시 입력 창과 이름을 유지합니다. 앱 재실행만 실패한 경우에도 실제 전환된 계정 상태를 다시 표시합니다.

## 설치

`OAuth Account Switcher-0.3.0-x64.exe`를 설치하거나 ZIP을 풀어 사용하세요. 기존 계정 저장 폴더와 채팅 및 설정은 유지됩니다.

## 검증 및 범위

- 릴리스 워크플로는 lint, TypeScript, 회귀 테스트, Windows PowerShell 구문 분석, COM interop 컴파일, Windows EXE 패키징, 패키징된 EXE 데모 실행 검사를 수행합니다.
- 데모 실행 검사는 실제 계정이나 인증 자료를 사용하지 않습니다. 개인 PC의 설치된 Codex를 통한 실제 OAuth 전환과 탐색기 프리징 재현 검증은 별도로 필요합니다.
- Microsoft Store/MSIX의 `OpenAI.Codex` 또는 `OpenAI.ChatGPT` 설치를 자동 실행 대상으로 찾습니다. 설치가 다르거나 실행 항목이 모호하면 전환된 인증은 유지하고 시작 메뉴에서 직접 실행하도록 안내합니다.
- 사용량 API가 기간을 반환하지 않으면 임의로 5시간이라고 붙이지 않습니다. 기존 저장 수치는 한 번 갱신하면 새 형식으로 바뀝니다.
- API의 일반 `pro` 표기만으로는 5x/20x 등급을 판단하지 않습니다. 등급을 확인할 수 없는 계정은 중립 가중치를 사용합니다.
