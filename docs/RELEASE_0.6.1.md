# v0.6.1

Windows 자동 시작 오류를 고치고, 잔여량 1% 알림과 더 쉬운 사용량 분석 화면을 제공합니다.

## 자동 시작 오류 수정

- 등록에 사용한 이름과 실제 확인하는 이름이 달라 정상 등록도 실패로 판단하던 문제를 고쳤습니다.
- 공백이 있는 EXE 경로를 따옴표로 감싸 Windows가 전체 경로를 실행하도록 수정했습니다.
- v0.6.0의 잘못된 등록이 남아 있으면 앱 시작 시 복구합니다. 작업 관리자에서 사용 안 함으로 바꾼 상태는 유지합니다.
- 설정에서 자동 시작을 바꾼 뒤 저장 상태를 일치시키고, 성공 후 이전 오류 메시지를 지웁니다.

설치 후 앱을 실행하고 **설정과 진단 → Windows 시작 시 자동 실행**을 확인하세요. 기존 오류 때문에 꺼진 설정은 다시 켤 수 있습니다. ZIP 버전의 실행 위치를 옮겼다면 새 위치에서 다시 켜 주세요.

## 잔여량 1% 알림

**설정과 진단 → 잔여량 알림 기준 → 1% 이하**를 선택할 수 있습니다. 기존 5/10/20/30%도 유지합니다. 변경한 기준은 다음 사용량 갱신부터 적용하며 같은 부족 상태에서는 반복 알림을 보내지 않습니다. Windows 알림 허용과 앱 실행이 필요합니다.

## 쉬워진 사용량 분석

- 사용 금액, 처리한 글의 양, 입력 재사용 비율, 캐시로 아낀 금액을 큰 숫자로 보여줍니다.
- 토큰과 캐시에 짧은 설명과 `?` 도움말을 붙였습니다. 리즈닝은 **생각 깊이**로 표시하고, 원래 옵션 이름도 함께 보여줍니다.
- 계정을 선택하면 사용한 주간 한도와 남은 한도를 막대로 볼 수 있습니다. 사용한 금액, 남은 금액, 전체 한도 금액의 추정값을 나란히 표시합니다.
- 기본 그래프는 달러 금액입니다. 토큰 그래프로 전환하거나 시간별, 날짜별, 주별, 월별로 볼 수 있습니다.
- 모델별 내역과 세부 기록, CSV 내보내기는 유지하고 계산 방식은 펼쳐서 읽도록 정리했습니다.

모든 금액은 **API 요금으로 환산한 달러 추정치이며 실제 구독 청구 금액이 아닙니다.** 이 PC에서 확인한 기록만 포함합니다. 자료가 부족하면 이유를 안내하고 금액을 만들어내지 않습니다. 단가와 계산 가정은 [v0.6.0 안내](https://github.com/kelvin926/codex-oauth-account-switcher/blob/main/docs/RELEASE_0.6.0.md)에서 확인할 수 있습니다.

## 검증

Windows에서 실제 Electron 등록 API와 별도의 테스트용 레지스트리 항목으로 공백 경로, 기존 오류 복구, 켜기와 끄기, 재실행 시 읽기, 작업 관리자 비활성화를 검사합니다. 테스트 항목은 검사 후 제거합니다. 1% 경계와 설정 복원, 분석 필터와 도움말을 검사하고, 전체 테스트와 EXE 화면 캡처가 성공한 뒤 배포합니다.
