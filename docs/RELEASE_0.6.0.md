# v0.6.0

스크롤 부담과 화면 설명을 줄이고, 자동 실행과 비용 분석을 추가했습니다.

## 변경 사항

- 스크롤 성능: GPU 가속 강제 비활성화를 제거했습니다. 전체 패널의 실시간 블러와 고정 배경을 없애고, 같은 데이터로는 화면을 다시 그리지 않습니다. 숨긴 창의 화면 조회를 멈추고 접힌 기록 표는 펼칠 때 렌더링합니다.
- 가독성: 작은 글자를 키우고 계정 카드를 넓혔습니다. 계정 요약은 계정 탭에만 표시합니다. 긴 설명은 `?` 도움말로, 추천 점수와 상세 이력은 접힌 영역으로 옮겼습니다. 도움말은 마우스, 키보드 포커스와 클릭으로 열고 Esc로 닫습니다.
- Windows 자동 시작: 기본으로 켜집니다. 새 버전을 한 번 실행하면 등록합니다. 트레이 유지가 켜져 있으면 로그인 후 창을 띄우지 않고 실행합니다. 설정에서 끌 수 있고 작업 관리자의 비활성화도 존중합니다. 개발 실행과 데모 캡처는 자동 시작을 등록하지 않습니다.
- 주기적 갱신: 기존 기본 5분 설정을 유지하고 상단에 간격을 표시합니다. 설정에서 1/2/5/10/15분 또는 끄기를 선택합니다. 토큰 수집이 계정 전환과 사용량 조회 작업을 기다리게 하지 않도록 분리했습니다.
- 주간 한도 복구 알림: 초기화 예정 시간이 같아도 주간 사용률 감소를 감지합니다. 반올림 잡음을 줄이기 위해 같은 초기화 시각에서는 1%p 이상 감소를 기준으로 합니다. 최초 기준값 없는 상태에서는 알리지 않고, 중복 또는 오래된 관측은 무시합니다. 기준값을 저장하므로 재시작 후에도 비교합니다. 잔여량 부족 알림과 독립적으로 켜고 끌 수 있습니다.
- 종료 중에는 새 인증 작업을 받지 않고 진행 중인 작업과 분석 기록 저장을 마친 뒤 종료합니다.

## 비용과 캐시 분석

기간, 날짜, 시간, 모델, 리즈닝 필터에 API 환산 비용과 캐시 적중률을 추가했습니다. 그래프는 토큰과 비용을 전환할 수 있고 CSV에도 함께 저장합니다.

- **API 환산액**: 일반 입력, 캐시 읽기, 기록된 캐시 쓰기, 출력에 각 단가를 적용합니다. 입력에 이미 포함된 캐시와 출력에 포함된 추론을 중복 합산하지 않습니다.
- **캐시 적중률**: 캐시 읽기 토큰 합계 / 입력 토큰 합계입니다. 요청별 비율을 단순 평균하지 않습니다. 캐시 정보가 없는 기록은 제외하고 일부 집계임을 표시합니다. 입력이 0이면 미확인입니다.
- **캐시 순절감액**: 캐시 없는 입력 환산액과 캐시를 적용한 환산액의 차이입니다. 캐시 쓰기가 많으면 음수일 수 있습니다.
- **한도 100% 환산**: 같은 계정과 초기화 주기에서 연속 관측된 15분 이내 구간의 환산 비용 합계 / 사용률 증가 합계 × 100입니다. 사용률이 반올림되어 그대로인 구간의 비용도 포함합니다. 주간 한도를 이미 전부 사용한 이후의 비용은 제외합니다. 1%p 이상 관측해야 표시합니다.
- **사용/잔여 금액 환산**: 추정한 한도 금액에 마지막으로 관측한 계정 전체 사용률을 적용합니다. 조회 종료 시각 이전의 최신 관측을 사용하며 모델과 리즈닝 필터와 독립적입니다.

**실제 구독 청구액이나 공식 보장 한도 금액이 아닙니다.** 다른 기기 사용, 기록 누락, 계정 귀속 추정과 단가 가정 때문에 오차가 있습니다. 자료가 없으면 0원을 만들어내지 않고 미확인 또는 추정 준비 중으로 표시합니다. 월 구독료를 단순히 4로 나누지 않습니다.

단가는 2026-09-26 확인한 API Standard 기준입니다. GPT-6 Astra/Sol/Luna와 GPT-5.6 Sol/Terra/Luna를 지원합니다. GPT-6은 입력 272K 초과 시 요청 전체 입력/캐시 2배와 출력 1.5배를 반영합니다. 확인하지 못한 GPT-5.6 장문맥 단가, 알 수 없는 모델, 다른 제공자는 비용 합계에서 제외하고 가격 확인 기록 수를 표시합니다. Fast 모드, 지역 가산과 도구 비용은 포함하지 않습니다. 과거 기록에도 이 기준 단가를 적용합니다.

캐시 쓰기 정보가 없으면 0으로 가정한 참고액입니다. 이전 버전 기록 중 캐시 수치가 0인 경우에는 실제 0과 누락을 구별할 수 없어 캐시 미확인으로 처리합니다. Codex 크레딧 청구에는 별도 캐시 쓰기 가산이 없으므로 API 환산액과 일치하지 않을 수 있습니다.

## 사용 안내

설치 후 앱을 한 번 실행하세요. 자동 시작 등록은 그때 적용됩니다. ZIP 버전은 실행 파일을 유지할 폴더에서 설정하세요. Windows 알림을 차단한 경우 토스트가 보이지 않습니다. 드라이버 문제로 GPU 호환 모드가 필요한 경우에만 `OAUTH_SWITCHER_DISABLE_GPU=1`로 실행할 수 있습니다.

핵심 비용 계산, 누락 데이터, 예상치의 분모, 캐시 중복 합산, 주간 초기화 감지, 설정 복원과 UI 필터를 테스트합니다. Windows 빌드의 린트, 전체 테스트, EXE 실행 검사와 캡처 검사를 통과한 후 릴리스됩니다. 사용자 PC의 실제 스크롤 프레임률은 이 환경에서 측정하지 않았습니다.
